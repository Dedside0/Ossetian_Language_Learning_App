# Ossetian_Language_Learning_App
# Адӕм - платформа для изучения осетинского языка.
## Цели.
Создать веб приложение, в котором преподаватели смогут создавать свои курсы с помощью шаблонов.
Создать мобильное приложение, в котором пользователи смогут проходить эти курсы.
## Задачи.
1. Создать конструктор для курсов, в который будут входить 3 шаблона: карточка, теория, тесты.
2. Создать модели для пользователя, преподавателя и админа
