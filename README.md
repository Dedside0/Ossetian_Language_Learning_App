# Демо-прототип проекта Adam - приложение для изучения осетинского языка
## Описание
Интерфейс разрабатываем под мобильное устройство.
Пользователь попадает на страницу со списком курсов (2-3 курса) и кнопкой добавиь курс.
### Если пользователь нажал на курс:
Открывается страница с уроками. 1 урок, состоящий из двух задач - лексика(переносит на карточки) и спряжение(переносит на тест со спряжением).
Перед каждым уроком небольшая вставка с теорией.
##### Описание карточек
Прямоугольная карточка с картинкой, словом на осетинском и кнопкой для воспроизведения аудио. При нажатии на карточку она переворачивается и слово на осетинском заменяется на слово на русском.
Тематика карточек: осетинские глаголы(возможно стоит добавить в карточку указание на тип глагола)
Количество карточек: 47. Снизу карточки будут две кнопки: продолжить(дает следующую карточку) и выйти(возвращает на страницу урока)
##### Описание теста на спряжение
Дается простое предложение на русском в прошедшем времени, пользователь должен написать его перевод на осетинский(можно попробовать здесь тоже добавлять сгенерированные картинки)
Количество предложений в тесте: 10. Нужно подумать как быть с клавиатурой. Возможно стоит добавить подсказки.
Снизу опять будут две кнопки: продолжить(дает следующее предложение) и выйти(возвращает на страницу урока). Кнопка продолжить будет появляться после ввода ответа пользователем
### Если пользователь нажал Добавить курс:
Открывается страница с 1 уроком, под которым есть кнопка добавить задание. При нажатии на кнопку открывается конструктор карточки.
#### Описание конструктора карточки
Имеется кнопка Добавить карточку. При нажатии открывается форма с двумя инпутами - слово на осетинском и слово на русском, а также кнопкой запсиси аудио с микрофона. Картинка генерируется по слову на русском.
После заполнения инпутов добавится кнопка Сохранить, по нажатию на которую форма закроется и на страницу конструктора добавится новая карточка.
Внизу конструктора будет кнопка готово, которая вернет на страницу урока с сохраненным заданием.
